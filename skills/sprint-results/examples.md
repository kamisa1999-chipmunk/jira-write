# Эталон итогов спринта

Файл задаёт **уровень полноты, баланс и язык**. Факты и формулировки из примера **не копировать** в другие спринты и не подставлять, если текущие данные их не подтверждают.

## Что переносить в каждый отчёт

- Короткая живая подводка по реальному содержанию спринта, не обязательная шутка.
- Баланс: прод, значимая текущая работа, технические улучшения.
- Обычно 5–8 содержательных пунктов, не три цели и не простыня тикетов.
- Этапы одной инициативы — один рассказ.
- У незавершённого: что сделали за спринт → где сейчас → ближайший этап.
- У техники: практический эффект без оправданий.
- Без Jira-канцелярита, внутренней кухни и раздутого бизнес-эффекта.
- Markdown буквально, без `\#`, `\-` и вложенных ссылок.

Число разделов и пунктов в примере — не квота.

## Golden example (стиль)

Ниже — ориентир плотности. Перед использованием каждого факта сверить JSON спринта. Если факт не подтверждён — спросить или скорректировать, не повторять автоматически.

```markdown
#demo #cat2 итоги 24/08 – 04/09

В этот раз без паузы между «выпустили» и «делаем дальше»: сертификаты и первый этап Chanel уже у пользователей, а следующие изменения готовятся следом.

### 🚀 Уже у пользователей

- Выпустили сертификаты качества на PDP — теперь документы можно открыть прямо из карточки товара. [CAT2-3970](https://jira01.goldapple.ru/browse/CAT2-3970)
- Запустили первый этап Chanel: Logo Bar и линия уже работают на сайте и в приложениях, например на [бренд-зоне Chanel](https://goldapple.kz/brands/chanel). Параллельно взяли в разработку второй этап — e-logo; завершаем разработку и готовим его к тестированию. [CAT2-3610](https://jira01.goldapple.ru/browse/CAT2-3610)
- Включили новые промокодные механики для всех пользователей в России.

### 🔧 Двигаем дальше

- Спроектировали разделение продуктовых лейблов по регионам. Системный анализ завершён, следующий этап — разработка. [CAT2-3641](https://jira01.goldapple.ru/browse/CAT2-3641)

### 🧹 Под капотом

- На Android обновили архитектуру экрана каталога и завершили тестирование. Единый подход упростит дальнейшую разработку и поддержку экрана. [CAT2-3976](https://jira01.goldapple.ru/browse/CAT2-3976)
- На Web перенесли часть запросов Beauties Store в BFF витрины и завершили тестирование. Убрали лишний слой между витриной и API: меньше точек отказа и проще диагностика. [CAT2-2962](https://jira01.goldapple.ru/browse/CAT2-2962)
```

## Типичная ошибка

Пост из трёх пунктов только по разделу «Цели» на странице спринта — слишком узкий, даже если цели закрыты. Смотреть `composition_candidates` и весь `issues`.

Не усиливать эффект. Нельзя писать «готовы к любым новым акциям», если речь шла о включении механик для всех пользователей в России.
